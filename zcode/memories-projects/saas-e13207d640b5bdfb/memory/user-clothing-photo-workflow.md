用户的工作场景是服装拍摄后期整理：一次拍摄 500–1000 张，目的是展示同一件衣服的不同姿势和角度状态，最终每个姿势角度组只留一张展示图。目标用户群体是服装电商运营/摄影师，运行环境为 macOS（M4 Max MacBook），要求 App 打开即用（非技术用户）。用户使用中文沟通。

工作偏好：
- 明确调用 ponytail 技能要求惰性高效开发（最小可用实现、能省则省），接受简单方案替代 PRD 中的重型技术栈（如用单文件 Python + 浏览器 UI 替代 Tauri+React 双栈），只要核心需求覆盖即可。
- 倾向本地优先：不申请开发者账号、不签名公证、本地化安装；输出方式选原位重命名而非复制新目录；进一步演进出完全离线的本地模型版（照片不出本机、零 API 费用）。
- **MVP 小步验证**：模型选型上明确要求"优先体积小的可用 MVP 模型，实测后再决定"；分发上要求"程序本体与模型下载模块分开"，模型走 App 内一键下载自动化适配。
- 决策果断，会对 PRD 遗留问题逐条给出明确答复；会中途追加指示（如"不要建 commit，新建独立 repo"），需要即时切换执行路径。
- 对易用性敏感：嫌终端操作麻烦，推动了"一条命令安装 + 双击启动"的安装器方案；遇到 Mac 拦截/按钮无反应等问题会直接截图反馈。

相关项目见 [[project-photocurator-prd]]。
