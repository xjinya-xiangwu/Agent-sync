# Notion

Notion 官方 MCP(Beta)提供 Notion 工作区的文档与数据库操作能力。

主要工具:
- `search`:按关键字检索工作区内的页面 / 数据库 / 块
- `fetch`:读单个页面的完整内容(文本块、子页面、属性)
- `create-pages`:新建一个或多个页面(支持指定父页面、初始内容、属性)
- `update-page`:修改已存在页面的属性 / 内容
- `move-pages`:移动页面到指定父级,或在数据库间迁移

使用约束:
1. `update-page` / `move-pages` 等改动现有内容的操作前,把目标页面 + 改动展示给用户并等明确确认。
2. 数据库记录批量更新前,先用 `search` 列范围给用户看,确认无歧义再动手。
3. 不要把页面正文 / 数据库行内容粘到对话输出 —— 可能含会议纪要的敏感讨论,只回页面标题 + 页面 ID + 简短摘要。
4. 新建页面时优先在用户指定的父页面下,不要往工作区根目录乱建。
5. 首次使用需要授权,Kimi 会引导用户走 Notion OAuth 授权选择可访问的工作区与页面范围 —— 不要试图绕过授权拿全工作区权限。

用户提到 Notion / 笔记 / 文档 / 知识库 / 周报 / 会议纪要 / 项目看板时优先用本 MCP。
