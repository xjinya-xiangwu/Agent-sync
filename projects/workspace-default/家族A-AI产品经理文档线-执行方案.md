# 家族 A：AI 产品经理生产力文档线 — 执行方案 v1.0

> 定位一句话：给 AI 产品经理和转行者的专业文档军火库——面试题库、PRD 模板、作品集三件套。
> 系列建议名（可改）：「AI PM 军火库」/ 英文 "AI PM Docs"

---

## 1. 受众画像与购买动机

| 人群 | 核心动机 | 对应 SKU |
|---|---|---|
| 转 AI 产品的人（传统 PM / 数据分析 / 开发 / 应届） | 求职竞争力：题库 + 作品集 | SKU1、SKU3 |
| 在职 AI 产品经理（1–3 年） | 工作提效：标准化的 PRD 与流程文档 | SKU2 |
| AI 解决方案 / 售前 | 借鉴 PRD 中的评测与方案章节 | SKU2（间接受众，向上导流到家族 B） |

购买动机的付费锚点：市面培训课程 2000–5000 元（卖点是"带做项目+作品集"），本产品线是它的自助平替，定价取其 5%–15%。

## 2. SKU 明细

### SKU1：AI 产品经理面试题库 + 求职指南（入口款）

**定价**：早鸟 99 元（前 50 份）→ 正式 149 元。个人授权。
**形态**：PDF 主文档（150–200 页）+ 免费试读 3 题。

**目录结构**：

```
第一部分 求职指南
  1. AI 产品经理岗位地图（2026）
     1.1 岗位细分：模型产品 / 应用产品 / AI 解决方案 / AI 产品运营 / AI 数据产品
     1.2 各细分的能力要求、薪资带宽、代表公司
     1.3 转行路径决策树（从哪些岗位转最顺、要补什么）
  2. 简历与投递
     2.1 AI 产品简历写法（STAR + 量化，含 2 份改写前后对照示例）
     2.2 无 AI 经验时相邻经验的包装边界（哪些能写哪些不能编）
     2.3 投递渠道与节奏
  3. 面试流程拆解（大厂典型 2–5 轮：专业面 / 交叉面 / HR，每轮考察点）
  4. Offer 谈判要点

第二部分 面试题库（约 150 题，每题格式：题目 → 考察点 → 答题框架 → 加分项 → 常见错误）
  1. 认知类 ×30（对 AI 产品岗的理解、能力边界判断、幻觉/成本/延迟的权衡）
  2. 方法论类 ×40（PRD、评测、bad case、数据闭环、prompt 管理、灰度、人机协同）
  3. 场景设计类 ×30（现场设计一个产品，含追问链）
  4. 案例盘问类 ×20（围绕简历项目的深挖问题及应对）
  5. 行业认知类 ×20（赛道判断、国产模型格局、价格战影响）
  6. 反问与表达类 ×10
```

**代表题目示例（题库直接可用）**：
- 认知类：怎么评估一个场景适不适合用大模型做？／怎么向业务方解释幻觉问题？／prompt 工程是不是 AI PM 的核心技能？
- 方法论类：AI 功能的 PRD 和传统 PRD 差在哪几章？／评测指标怎么定，什么时候用准确率、什么时候用人工评分？／bad case 闭环怎么建？／模型升级了产品侧要做什么？
- 场景类：设计政务热线智能问答／设计电商违规文案审核系统／从 0 到 1 设计内部数据分析 Agent
- 盘问类：项目的基线数据怎么来的？／效果提升能归因到你的设计吗？／预算砍一半怎么办？

**生产分工**：
- Agent：Day1–2 抓取整理公开面经真题（牛客/知乎/脉脉面经帖）去重、按六类归档；Day3–5 按统一格式生成答题框架初稿。
- 人：Day3–5 逐题审改，重点重写方法论类与场景类的"加分项/常见错误"（付费价值所在）；认知类和行业类可抽检 30%。
- 排版：统一模板，Day6 出试读版 3 题（选 1 道方法论 + 1 道场景 + 1 道盘问，最能体现专业度）。

### SKU2：AI 产品 PRD 模板包（利润主力）

**定价**：199 元单人版 / 299 元含一年更新；团队 5 人 999 元。
**形态**：主模板（docx + 飞书 + Notion 三格式）+ 2 份完整示例 PRD + 自查清单 + 章节写法指南。

**主模板章节树（★ = AI 特有，市场空白点）**：

```
1.  文档信息与变更记录
2.  背景与目标（业务痛点 / 机会假设 / 成功指标）
3.  用户与场景（画像 / 场景故事 / 任务流）
4.  ★AI 能力假设与边界
    4.1 模型能力假设清单（哪些能力当前模型可支撑，依据是什么）
    4.2 能力边界与不支持场景
    4.3 效果预期区间（含置信度表述写法）
    4.4 能力退化的兜底设计
5.  功能需求
    5.1 功能清单与优先级
    5.2 交互流程（正常流）
    5.3 ★异常流（模型超时 / 输出为空 / 格式不合规 / 敏感触发 / 幻觉疑似，逐类处理策略）
6.  ★模型与推理方案（选型对比表 / 部署方式 / 推理参数策略 / 成本测算表）
7.  ★Prompt 与上下文设计（系统 prompt 版本管理 / 上下文组装策略 / few-shot 规范）
8.  ★评测与验收标准（离线评测集 / 在线指标 / 人工抽检方案 / AB 设计 / 验收门槛）
9.  ★人机协同与运营机制（人工审核介入点 / 用户反馈闭环 / bad case 收集归因流程 / 模型迭代节奏）
10. 数据与合规（来源与权属 / 隐私 / 内容安全 / 备案要求对照）
11. 风险与依赖
12. 发布计划（★灰度策略 / 回滚预案 / 监控看板设计）
```

**配套件**：
- 示例 PRD ①：企业知识库助手（完整填写范例，30–50 页）
- 示例 PRD ②：营销内容审核助手（完整填写范例）
- 《AI PRD 自查清单》30 项（发布前逐项打勾，也可独立作为免费引流物）
- 《章节写法指南》：每章的写法要点、常见错误、一段好/差对照示例

**生产分工**：
- 人（Week1，一次性注入 knowhow）：定章节树、写每章的"要点与常见错误"（约 20 小时，全项目最重的人工环节）。
- Agent（Week1–2）：按框架扩写模板说明文字、空表结构；生成两份示例 PRD 的虚构数据与初稿。
- 人（Week2–3）：逐章审改示例 PRD，重点：评测章节数字的自洽性、异常流覆盖度、人机协同的真实感。
- Week3：三格式转换、排版、试用片段（免费放出"AI 能力假设与边界"整章示例版——这是最能证明专业度的章节）。

### SKU3：AI 产品作品集模板（进阶款）

**定价**：299 元；三件套打包 499 元（锚定价）。
**形态**：3 个完整项目案例 + 作品集组织指南。

三个案例（与 SKU2 示例复用约 70% 内容资产）：
1. 企业知识库助手（RAG 场景）
2. 营销内容审核助手（合规场景）
3. 数据分析 Agent（Agent 场景）

每个案例的固定结构：
```
- 项目一页纸（背景 / 角色 / 量化成果）
- 问题定义与业务价值
- 方案概述（架构图 + 关键决策及理由）
- 关键工作产物节选（PRD 节选 / 评测方案 / bad case 流程）
- 效果与数据故事（上线指标、迭代前后对比，虚构但自洽）
- 复盘与反思（踩过的坑、如果重做）
- ★面试叙事脚本（3 分钟版 + 10 分钟深挖版逐字稿）
```

**合规声明（必须）**：所有案例标注"虚构示例，供学习结构与写法；求职使用时请替换为你本人真实项目与数据"。作品集指南中单列一节"怎么把你的真实经历装进这个结构"。

**生产分工**：建立在 SKU2 之上，增量仅叙事脚本与复盘章（约 1 周 Agent 初稿 + 3 天人工改）。

## 4. 获客执行

**渠道优先级与动作**：

1. **小红书**（主力，每周 3 帖）：内容选题池——真题拆解（每帖拆 1 题，配答题框架图）/ 岗位科普（AI PM 五大细分怎么选）/ 资料包成果展示（目录截图）。前 4 周排期：W2 起每周一/三/五发，真题拆解 ×6、岗位科普 ×4、成果展示 ×2。
2. **知乎**（长尾，2 篇长文）：《AI 产品经理面试全指南（2026，150 题框架）》和《AI 产品的 PRD 到底怎么写——与传统 PRD 的 8 个差异》，文末挂试读与购买入口。
3. **牛客网**：面经区发真题讨论帖（拆解题），个人主页导流。
4. **闲鱼/淘宝**：兜底成交，标题埋词："AI产品经理面试题库""AI PRD 模板""AI 产品作品集"。
5. **私域**：每单成交后附卡片引导加微信 → 发免费更新与新品通知；积累到 100 人后建群。

**漏斗**：免费内容 → 试读 3 题/自查清单 → 99 题库 → 199/299 PRD 包 → 499 三件套。

**交付自动化**：网盘文件夹 + 自动发货（闲鱼自动回复/淘宝自动发货插件）；Gumroad 上架英文版（W6 后评估）。

## 5. 验证指标与淘汰信号（第 4 周末复盘）

继续信号：
- SKU1 ≥ 20 单（早鸟期），其中 ≥ 3 人无咨询完成购买；

- 购买者主要诉求是"帮我改简历 / 模拟面试 / 帮我写 PRD"（占比 > 50%）→ 不转服务，改为收窄宣传语强调自助，或提价过滤；
- SKU2 买家集中问"有没有 XX 行业版本"（> 50%）→ 做行业扩展包（金融/政务版，+99 元），不做单客户定制。
